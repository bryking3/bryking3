## Woran ich gerade arbeite

### 🏐 Volleyball-Abwehr

Kamera-Feedback für mein Abwehrtraining. Eine Stimme ruft Zahlen wie auf einem
Zifferblatt (1–12), ich bewege mich in die passende Abwehrposition, und eine
Kamera schaut zu. Per Pose-Tracking (MediaPipe, OpenCV) erkennt das Programm
meine Gelenkpunkte und prüft:

- **Richtung:** Bin ich in der richtigen Position gelandet?
- **Tempo:** Wie schnell habe ich reagiert?
- **Technik:** Stimmen Armhaltung, Standbreite und Oberkörper?

Die Rückmeldung kommt per Stimme, damit ich nicht auf den Bildschirm schauen
muss. Ziel sind konkrete Hinweise wie „Arme höher“ oder „Beine enger“.
Nebenbei lerne ich daran agiles Arbeiten mit Jira und GitHub.
